# Exercises

Personal software engineering exercises and hands-on technical labs.

## Folders

### `kubernetes/`

Kubernetes exercises built around a three-tier application running locally on
KIND. The stack includes a Python/Flask API, PostgreSQL, Docker, Kubernetes
Deployments and Services, persistent storage, ConfigMaps, Secrets, Ingress, and
Datadog. The exercises cover application deployment, load balancing,
configuration and secret management, database persistence, and observability
through metrics, distributed traces, structured logs, and simulated healthy,
slow, and failing requests.

### `coding_questions/`

A collection of coding exercises with problem descriptions, implementations,
and automated tests.
